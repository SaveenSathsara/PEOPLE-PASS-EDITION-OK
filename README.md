# @ SPOS POS System 2026 1.1.2

This is a custom re-creation of the **@ SPOS POS System** with a professional "retro" aesthetic, as requested.

## Softwares Included:
1. **POS (Point of Sale)**: Front-office terminal for processing sales and billing.
2. **Back Office**: Inventory management, supplier tracking, and administrative controls.
3. **Accounting**: Financial ledger, Profit & Loss reports, and basic accounting.
4. **Barcode Printing**: Utility to generate and print item barcodes.
5. **Database Manual Backup**: System maintenance and data safety utility.
6. **User Management**: Module for adding, editing, and managing system users and permissions.

## How to Run:
1. Navigate to the folder: `D:\S POS 2026 1.1.2`
2. Open the file `index.html` in any modern web browser (Google Chrome, Microsoft Edge, or Firefox).
3. The system will start with the **Login Screen**.
4. Click **Log In** to proceed to the **Control Center**.

## System Features:
- **Responsive Layout**: Designed to look like a classic desktop application.
- **Mock Logic**: Includes simulated cart additions in POS and backup progress in the Database utility.
- **Shared Design System**: Uses a centralized `styles/global.css` for a consistent look across all modules.
